Installation Guide

Step 1: Install the Chrome extension from the Web Store (link coming soon)
Step 2: Download and install the companion app:
git clone https://github.com/damlalper/rearead-eyetracking
cd ReaRead2/companion && pip install -r requirements.txt
Step 3: Run the companion app:
python main.py
Step 4: Click the extension icon and follow the calibration wizard
Step 5: Start reading on any webpage and enjoy AI-powered reading assistance!

Requirements: Python 3.11+, Webcam, Chrome Browser
